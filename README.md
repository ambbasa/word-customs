# 단어 세관 (WORD CUSTOMS) — 되찾은 말들

2087년 국가 언어관리 AI 「NULL」이 핵심 어휘 4,200개를 통제하는 사회에서, 경계 세관 제7창구 심사관이 되어 편지와 노래와 일기를 심사하는 **30일 풀 캠페인 브라우저 게임**입니다.

- **플레이 링크 (GitHub Pages)**: https://ambbasa.github.io/word-customs/
- **설계 변경 및 차별화 문서**: [`docs/DESIGN_UPDATES.md`](docs/DESIGN_UPDATES.md)

## 핵심 시스템
- **30일 캠페인 (`D01~D30`)**: 336건의 화물, 40건의 기억 화물, 규칙 `R01~R15` 누적, 방해 요소 5종(압박 대사·감찰관 동석·측정기 고장·규칙 개정·대기열 폭주), 20종 엔딩 분기.
- **4가지 심사 판정**:
  - `통과 (1)` · `압수 (2)` · `수정 (3)` (한글 IME 조합 지원·열린 한국어 일상 어휘·미리 측정 지원) · **`먹칠 (4)`** (위반 낱말을 `███`로 가려 안전 통과하되 보너스·기억 복원을 포기하는 도덕적 타협안).
- **『단어 세관』만의 독자적 차별화 요소**:
  1. **언어 전염 (Language Drift) & NULL 역공**: 내가 지어낸 대체어가 시민 대사와 하람의 말투로 퍼지며, 같은 대체어를 3회 이상 남용하면 NULL이 감시 보정(`+8`)을 걸어 새로운 표현을 유도합니다.
  2. **2D 의미 별자리 레이더**: 측정기에서 아날로그 다이얼과 2D 의미 별자리 지도를 전환해 금지어와의 거리를 공간적으로 추리할 수 있습니다.
  3. **NULL 실시간 심리전**: 화물 앞에서 오래 망설이면 NULL 슬릿에 실시간 경고·관찰 멘트가 출력됩니다.
  4. **감각 복원 레이어**: 기억을 복원할수록 저녁 부엌의 색채가 주황빛으로 살아나고, 복원 수에 비례해 Web Audio 피아노 합주 레이어가 쌓입니다.
- **스팀 상용화급 아트 & 다국어 아키텍처**:
  - 2087 디스토피아 브러시드 스틸 UI 프레임 + 통일된 페인터리 일러스트 13종(`assets/`).
  - `stages/locales/`(`adapter.js`, `ko-KR.js`, `en-US.js`)로 한국어·영어 확장 구조를 분리했습니다.

## 주요 단축키
- `N`: 다음 손님 호출
- `1` / `2` / `3` / `4`: 통과 / 압수 / 수정 / 먹칠
- `M` / `Shift+M`: 빠른 측정 / 정밀 측정
- `Space`: 대조 모드 토글 (`D4~`)
- `F1` / `F2`: 규칙집 / 복원 사전
- `Esc`: 설정 · 일시정지
