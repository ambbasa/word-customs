# 단어 세관 (WORD CUSTOMS) — 되찾은 말들

기획서 Ver 4.0을 기반으로 구현한 **D1~D5 수직 슬라이스** 브라우저 게임입니다.

- **플레이 링크 (GitHub Pages)**: https://ambbasa.github.io/word-customs/
- **구현 범위**:
  - 인트로 방송(NULL 원문) → 아침 공문 → 근무(창구·책상·규칙집·측정기·도장) → 퇴근 정산(야간 표본 감사·생활비) → 저녁(가족 대화·서연의 조언·기억 복원 4단계 연출)
  - D1~D5 캠페인 (규칙 R01~R05, 통제 어휘 자유·사랑·감정어 12종, 하준의 엄마 편지·노을의 가사 딜레마)
  - 시드 고정 유사도 측정기 Lv1, 한글 IME 조합 대응 인라인 수정 및 보존율 P 채점, 대조 모드(`Space`), Web Audio 효과음·피아노 모티프, 접근성 설정(느긋한 근무, 정자체 보기, 색약 모드)

## 주요 단축키
- `N`: 다음 손님 호출
- `1` / `2` / `3`: 통과 / 압수 / 수정 도장
- `M` / `Shift+M`: 빠른 측정 / 정밀 측정
- `Space`: 대조 모드 토글 (D4~)
- `F2`: 복원 사전 열기
- `Esc`: 설정 / 일시정지
